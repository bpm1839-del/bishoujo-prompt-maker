# 美少女プロンプトメーカー Ver.1.4

Windows/Tkinter版のソース公開リポジトリです。WEBアプリ化の構成・保存形式の引き継ぎは [WEB_MIGRATION.md](WEB_MIGRATION.md) を参照してください。
実ユーザーの保存データやモデル重みは含みません。

Windows用Python/Tkinterアプリ。標準ライブラリだけで動作します。
Forge / Animagine XL向けの英語プロンプトを作り、画像生成はForge側で行います。

## 起動・Ver.1.3からの更新

1. ZIPを新しいフォルダーへ「すべて展開」します。旧フォルダーへ上書きする必要はありません。
2. Python 3.10以降（Tcl/Tk付き）を用意します。
3. 起動中の旧版を終了し、新フォルダーの **START.bat** をダブルクリックします。
4. 左でプリセットを選び「プロンプト生成」。右側のPositive/NegativeをそれぞれコピーしてForgeへ貼り付けます。

```powershell
py -3 app.py
```

`py` がなければ `python app.py`。Tkの確認は `py -3 -m tkinter`。
Python配布元：https://www.python.org/downloads/windows/

保存先は従来と同じです：

```text
%LOCALAPPDATA%\BishoujoPromptMaker
```

BPM_DATA_DIRを設定していた場合は同じ指定を使います。起動前にこの保存先全体をコピーしておけば、以前の状態へ戻せます。

- 既存のプリセット・お気に入り・選択・ロック・強調度・モデル・生成設定・直接編集文章を引き継ぎます。
- 初期辞書は612件。Ver.1.3の610件の全既存フィールドを維持し、10代と四つん這いの2件を追加しました。
- 旧環境にも新2件をメモリー上で追加します。既存の編集・削除・ユーザーIDを維持し、同じ出力先の英語タグ全体、または同じタブ・カテゴリの日本語名が登録済みなら重複追加しません。
- 起動だけでは既存JSONを上書き・初期化しません。明示的な保存時には元JSONを `ファイル名.pre-v1.4.bak` に初回だけコピーし、その後保存します。以前のバックアップも残します。
- presets.json保存時にcatalog.jsonのversionを14へ更新し、他メタデータは維持します。新2件も一度削除・保存したら再起動で復活しません。
- 旧お気に入りに新しい衣装色・壁紙設定がない場合は、色と完成サイズは「指定なし」で読み込みます。従来の選択内容と右の文章は残します。
- 別バージョンとの同時起動は避けてください。戻す時は両方を閉じ、全体バックアップまたは必要なpre-v1.4.bakを復元して旧版を使います。

## 今回追加・改善したもの

### 見やすいグリッドと配色

左の一覧に薄い縦線・横線を追加し、行を淡く交互に色分けしました。アイボリーの背景、くすみピンクのタブ、ラベンダーの選択色を使っています。文字は濃いグレーです。
Tkinterの左右ペインと既存タブ構成は維持しています。起動サイズ1260×820、最小900×620も従来と同じです。行高は読みやすく24ピクセルに調整しました。

### 年齢・姿勢

- キャラクター→年齢：**10代 / teenage** を追加。年齢プルダウンの先頭に表示します。
- ポーズ・構図→姿勢：**四つん這い / all fours** を追加。

年齢は指定なし・10代・20代前半・20代後半・30代から1種類。初期値は指定なしです。身長・体型・バストサイズの独立した単一選択も維持しています。
新規10代項目はランダム対象外で、手動で選びます。既存の年齢グループと同じく、別の年齢を選べば前の選択を解除します。
「正面 / front view」と「こちらを見る / looking at viewer」は従来通り別々に選べます。

### 衣装ごとの色

1. 衣装一覧でコートとシャツなど、色を付けたい衣装をチェックします。
2. **「選んだ衣装の色…」** を押します。
3. 衣装ごとに色を選び、**適用** を押します。
4. 「プロンプト生成」で右側に反映します。

例：

| 衣装 | 色 | 出力 |
| --- | --- | --- |
| コート | 黒 | black coat |
| シャツ | 赤 | red shirt |

初期値は指定なし。白・黒・赤・青・緑・黄色・紫・ピンク・茶色・灰色・ベージュ・紺・水色・アイボリー・オレンジ・金色・銀色を選べます。

- 衣装チェックを外すと出力対象から外れますが、色設定は保持します。再度選べば同じ色を使えます。
- 「キャミソール＋ショーツ」のような複合項目では、構成する衣装ごとに別の色を指定できます。
- 既に色を含むタグは、先頭の既知の色を置き換えます。例：white shirtへ赤を指定するとred shirtになります。
- 強調度1.2なら `(black coat:1.2)`。左の個別コピーにも同じ色・強調度を反映します。
- 元プリセットの英語・日本語を直接書き換えず、現在の作業・お気に入りの追加設定として保存します。日本語ツールチップにも色を付けた衣装名を反映します。
- 装飾・アクセサリーなど、Positiveの衣装タブの項目にも指定できます。特殊な独自タグではモデルに応じて調整してください。
- コートとシャツのような重ね着で不要な警告が出ないよう、「基本服」の警告を上着・羽織り・ニット・ワンピース・トップスで分けました。同じ種類の候補が複数ある場合は引き続き警告します。

**旧「服の色」カテゴリ**は通常の一覧・ランダム対象から外しています。保存データからは削除しません。
必要なら衣装タブの **「旧色タグを表示」** をONにします。旧お気に入りの色タグもそのまま出力し、「選択中だけ」でも見つけて解除できます。
衣装ごとの色と旧色タグを同時に使うと広い範囲の色指定が重なるため、旧お気に入りを調整する際は選択内容を確認してください。

### 壁紙の完成サイズ・生成サイズ

右側に「壁紙・完成サイズ」を追加しました。完成サイズを選ぶと幅・高さへ推奨生成サイズを反映し、拡大倍率を表示します。

| 完成サイズ | 推奨生成サイズ | 比率 | 拡大倍率 |
| --- | --- | --- | --- |
| 正方形 1024×1024 | 1024×1024 | 1:1 | 1倍 |
| FHD 1920×1080 | 1280×720 | 16:9 | 1.5倍 |
| WQHD 2560×1440 | 1280×720 | 16:9 | 2倍 |
| 4K 3840×2160 | 1280×720 | 16:9 | 3倍 |
| ウルトラワイド 2560×1080 | 1536×648 | 64:27 | 約1.67倍 |
| ウルトラワイド 3440×1440 | 1376×576 | 43:18 | 2.5倍 |
| スマホ縦長 1080×1920 | 720×1280 | 9:16 | 1.5倍 |

すべて幅・高さは8の倍数で、完成サイズと生成サイズの比率が一致します。推奨生成サイズは約1メガピクセル以下です。
「推奨生成サイズ」で再反映、「完成サイズを直接設定」で完成サイズを幅・高さへ入れることもできます。直接数値編集も可能です。指定なしでは幅・高さを変更しません。

**Forgeへの自動送信・自動拡大は行いません。** 最初の生成サイズ、必要に応じてHires.fixなどでの拡大倍率・仕上げサイズをForgeへ手動設定します。生成負荷や適切な拡大方法はモデルと環境によって異なります。

### 人物の配置

「指定なし・左寄せ・中央・右寄せ」を選べます。既存のsubject on left / centered composition / subject on rightを再利用し、以前の配置選択を置き換えます。
「指定なし」はこの3つの配置タグを解除します。ほかの構図や視線は維持します。
旧環境で対象の配置プリセット自体を削除済みなら、自動復活させずにステータス欄で不足する英語タグを案内します。
配置は生成への指示です。実際の画像の位置や余白はモデルに依存します。

### 選択中だけ・ひとつ戻る・お気に入り

- 検索欄横の **「選択中だけ」** で、現在チェックされている項目だけ表示します。検索とカテゴリ絞り込みを併用できます。チェックを外すと一覧から消えますが、「ひとつ戻る」で復元できます。
- **「ひとつ戻る」** は直前の選択・一括操作・ランダム・ロック・強調度・衣装の色・壁紙サイズ・配置・お気に入り読込の選択設定を戻します。最大30操作分、現在の起動中だけ保持します。
- 元に戻す操作では、右側の生成済み・直接編集済み文章を上書きしません。必要なら生成ボタンで改めて反映します。
- プリセットの追加・編集・削除そのものや、ディスクへの保存は元に戻しません。削除した項目を履歴で復活させることもありません。
- お気に入りには従来内容に加えて、衣装ごとの色・完成サイズ・配置も保存します。壁紙用にまとめて保存・読込できます。

## 維持した操作

### タブ・検索・一覧

Positive/Negativeそれぞれに、キャラクター／衣装／ポーズ・構図／背景・雰囲気／画質・生成設定の5カテゴリがあります。
チェック欄でON/OFF、項目名をCtrl/Shiftで複数選択しSpaceでも切替。固定欄でロック。左右の境界をドラッグして幅を変更できます。
日本語・英語・カテゴリの部分一致検索、カテゴリ絞り込み、表示行の一括選択・解除を維持しています。

### 強調度・管理・ランダム

項目名を選び、強調度0.5〜1.5（0.1刻み）を指定して適用します。追加・編集ダイアログでも指定できます。
モデル既定タグと重なる場合は選択項目の強調度を優先。同じタグが複数の選択項目で重なる場合は、辞書順で先の項目を採用し、タグを重複排除します。
英語欄に直接入力済みの強調表記は保持し、1.0以外の設定を追加すると外側の強調を重ねます。

追加／編集／複製／削除、出力先指定を維持しています。同じ出力先の英語タグ全体、または同じタブ・カテゴリの日本語名の重複を防ぎます。複製する場合は英語と日本語名またはカテゴリを変更してください。

ランダムはチェックしたPositiveカテゴリから各1項目を選びます。固定された選択を保持し、固定OFFを抽選から除外。同じ排他グループからの追加抽選を避けます。Negativeと初期Positive nsfwは対象外です。
nsfwは両側で使用でき、両側選択時は警告します。任意の自由入力全体の意味を解析するものではありません。

### 個別コピー・全文コピー・日本語訳

左の各行の「コピー」は未チェックでも使え、英語だけを現在の色・強調度でコピーします。チェック・行選択・右の本文を変更しません。
右側の全文コピーボタンはそのままです。右には個別コピーボタンを追加していません。

右側の英語タグへマウスを重ねると日本語名を表示します。数値付き強調・括弧内カンマ・ネスト・改行に対応。未登録は「日本語訳未登録」、長い名前は折返し・必要に応じ省略します。
本文・フォーカス・選択は変えず、入力・削除・コピー・貼付を妨げません。欄外・入力・クリック・スクロールで閉じます。本文変更後に解析し、通常のマウス移動ではキャッシュを使います。

翻訳は同じ出力先の独立したプリセット名を優先し、同条件なら辞書順で先のものを使用。独立したタグがない場合は複合プリセット名を「一部」として表示します。
保存先へtranslations.jsonをUTF-8で追加すれば未登録タグの訳を追加できます。既存プリセット名が最優先です。ネット翻訳APIは使いません。

```json
{"my custom tag":"自分の日本語訳"}
```

数値のない暗黙の強調係数、LoRAやスケジュール構文の意味は推測しません。極端なネストは深度64で打ち切ります。

### 直接編集・保存

右の文章は直接編集可能です。未保存の直接編集を再生成・お気に入り読込で上書きする前に確認します。
作業保存には選択・ロック・強調度・衣装の色・完成サイズ・モデル・Forge設定・ランダム対象・文章を含みます。お気に入りにも保存でき、同名上書きと削除には確認があります。
終了時は保存して終了／保存せず終了／キャンセル。プリセット管理とお気に入り変更は操作時に即保存され、終了時に取り消しません。

「全プリセットを初期化」は従来通り確認付きの手動操作です。初期612件に戻し、強調度1.0、衣装の色も指定なしへ戻します。アップデート時に自動実行しません。

## 保存・モデル拡張

| ファイル | 内容 |
| --- | --- |
| presets.json | ユーザー辞書・項目の初期強調度 |
| session.json | 最後に保存した作業・色・壁紙設定 |
| favorites.json | お気に入り |
| models.json | モデルプロファイル |
| catalog.json | 移行済みバージョン（14） |
| translations.json | 任意の補助翻訳辞書 |

JSONは一時ファイルから置換して保存します。破損・形式不正は警告して.brokenコピーを残し、初期値で開きます。この場合も起動時に元JSONを上書きしません。
初期モデルはAnimagine XL 3.1と汎用SDXL。保存先のmodels.jsonへ以下形式の新しいキーを追加して再起動すれば、別モデルのタグ設定も追加できます。既存キーを残して編集してください。

```json
{"自分のモデル名":{"prefix":"1girl, solo","suffix":"masterpiece, best quality","negative":"low quality, text, watermark"}}
```

アプリは画像モデル自体を読み込みません。初期品質タグの参照：https://huggingface.co/cagliostrolab/animagine-xl-3.1

## EXE化（任意）

このZIPはPythonソース版で、EXEは同梱していません。Windows上でBUILD_EXE.batを実行するとPyInstallerをインストールしてビルドします。インストール時はネット接続が必要です。

```powershell
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --noconfirm --clean --onefile --windowed --name BishoujoPromptMaker --add-data "defaults.json:." --add-data "models.json:." --add-data "translations.json:." app.py
```

生成先：dist\BishoujoPromptMaker.exe。調査時は--windowedを外してコンソールで確認します。
EXEビルドと配布先での実行は今回未検証です。公式：https://pyinstaller.org/en/stable/usage.html
